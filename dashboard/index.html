How the radar works

The board says a protocol records no token, never that it has none: the snapshot is a record, not proof. A protocol whose token already trades is set aside and used only to fit the model. Implied value is this entry's own claim about what a launch would be worth if the protocol's record stayed as it is — not a prediction that a token will launch, or when.
